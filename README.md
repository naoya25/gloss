# Gloss

文章や画像を貼ると訳が出て、分からない単語をその場で質問できる macOS アプリ(日本語⇔英語)。
質問すると、AI が選んだ範囲から覚えるべき単語やフレーズを抜き出して、単語帳に保存する。

## 使い方

1. 文章か画像を ⌘V で貼り付ける(画像はドラッグ&ドロップでも可)。貼った瞬間に翻訳が始まる
2. 原文か訳文の単語をダブルクリックするか、フレーズをドラッグで選ぶと、右のパネルで意味を説明してくれる(60字以内・1行の範囲。長い選択やキーボードで選んだときは ⌘L)
3. 「ニュアンス」「例文」「使う場面」のボタンか、自由入力でさらに聞ける
4. 説明は選んだ範囲の全体について出る。単語帳に入るのは選んだ範囲ではなく、AI がそこから抜き出した覚えるべき単語とフレーズ全部。答えが出た時点で自動で入り、パネルの表現を押すと外せる(もう一度押すと戻る)

5. サイドバーの「単語帳」はフラッシュカードになっている。カードを押すと裏返って答えが出て、裏で「覚えてない / あやしい / 覚えた」をつけられる。ツールバーで表の言語(英語 / 日本語)と並び順(しばらく見ていない順 / めくった回数が少ない順 / 覚えていない順 / 追加した順)を切り替える

画像を貼ったときは、画像の文字を書き起こして原文欄に入れる。英語の画像でも単語を選んで質問できる。

## 設定

⌘, で翻訳エンジン(JAPAN AI Gateway / OpenAI / Gemini)・モデル・JAPAN AI のユーザーID を変えられる。
初回起動時は TraPoP の設定を引き継ぐ。

API キーは設定画面(⌘,)の「API キー」欄に貼り付けて「保存」で登録する。
保存先は TraPoP と同じ Keychain の項目(`trapop-jai` / `trapop-openai` / `trapop-gemini`)で、TraPoP 側のキーも同時に変わる。

データは `~/Library/Application Support/Gloss/` に JSON で保存する。

## ビルド

```sh
./scripts/build-app.sh   # build/Gloss.app ができる
./scripts/install.sh     # build/Gloss.app を作って ~/Applications/Gloss.app に入れる(前のものは置き換える)
swift test               # GlossCore のテスト
```

Xcode 26 / Swift 6.3 / macOS 14 以上。
