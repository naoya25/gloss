# Gloss

**訳して、選んで、覚える。**

文章や画像を貼るとすぐ訳が出て、分からないところを選ぶだけで解説してくれる macOS アプリ。<br>
解説から覚えるべき単語とフレーズを AI が抜き出して、そのまま単語帳になる。

macOS 14 以上 · 日本語 ⇄ 英語 · JAPAN AI Gateway / OpenAI / Gemini

</div>

---

## できること

| | |
|---|---|
| **貼るだけで翻訳** | 文章か画像を ⌘V で貼った瞬間に訳し始める。画像は文字を書き起こして原文欄に入れる |
| **選ぶだけで解説** | 単語のダブルクリックか、フレーズのドラッグで、右のパネルに選んだ範囲全体の解説が出る |
| **覚える表現を自動で保存** | 選んだ範囲そのものではなく、AI が抜き出した「覚えるべき単語とフレーズ」を全部単語帳に入れる |
| **フラッシュカード** | 1行のカードを押すと、文字がほどけるように訳へ入れ替わる。解説・用例・例文は右のパネルに出る |
| **翻訳キャッシュ** | 前に訳した文は AI に送らず、履歴の訳をすぐ出す |

## 使い方

### 翻訳して質問する

1. 文章か画像を **⌘V** で貼る(画像はドラッグ&ドロップでもいい)
2. 分からないところを選ぶ
   - 単語は**ダブルクリック**
   - フレーズは**ドラッグ**(60字以内・1行まで)
   - 長い範囲やキーボードで選んだときは **⌘L**
3. 右のパネルに解説が出る。「ニュアンス」「例文」「使う場面」のボタンか、下の入力欄でさらに聞ける

選んだ範囲の区切り方から誤解していそうなときは、それも指摘するよう AI に頼んでいる。
たとえば `Everyone is welcome to stop by and grab a drink.` の `to stop` を選んだら、
`stop by`(立ち寄る)でひとかたまりだ、という説明が出るのがねらい。

### 単語帳に入るもの

解説が出きった時点で、AI が抜き出した表現がパネルのタイトルの下に並び、全部が単語帳に入る。

- 🔖 を押すと単語帳から外せる。もう一度押すと、めくった回数などの記録ごと戻る
- 覚える価値のある表現がなければ、何も入らない

### 単語帳で覚える

サイドバーの「単語帳」はフラッシュカードになっている。

| 操作 | 動き |
|---|---|
| カードを押す | 訳に入れ替わり、右のパネルに解説・用例・例文が出る。続けて質問もできる |
| もう一度押す | 表に戻る。パネルは開いたまま中身だけ消える |
| 裏の ✕ / ? / ✓ | 覚えた度合い(覚えてない / あやしい / 覚えた)をつける |
| 右クリック | 訳と例文を作り直す / 単語帳から削除 |

ツールバーで、表に出す言語(英語 / 日本語)と並び順を切り替えられる。
並び順は「しばらく見ていない順」「めくった回数が少ない順」「覚えていない順」「追加した順」の4つ。

### 履歴

サイドバーの「履歴」に、訳した文が新しい順で並ぶ。押すと翻訳画面で開く。

同じ文を同じ翻訳先で訳したことがあれば、AI に送らずに履歴の訳を出す。
そのときは翻訳ボタンの横に「↻ 履歴から表示」が出て、押すと訳し直す。履歴には同じ文を1件だけ残す。

## キーボードショートカット

| キー | 動き |
|---|---|
| ⌘V | 文章か画像を貼って翻訳 |
| ⌘↩ | 翻訳 |
| ⌘L | 選んだ範囲を質問 |
| ⌘N | 新規翻訳 |
| ⌘, | 設定 |

## 設定

**⌘,** で、翻訳エンジン(JAPAN AI Gateway / OpenAI / Gemini)・モデル・JAPAN AI のユーザーID を変えられる。
初めて起動したときは、TraPoP の設定を引き継ぐ。

API キーは設定画面の「API キー」欄に貼って「保存」で登録する。

> [!NOTE]
> キーの保存先は TraPoP と同じ Keychain の項目(`trapop-jai` / `trapop-openai` / `trapop-gemini`)。
> Gloss でキーを変えると、TraPoP 側のキーも同時に変わる。

単語帳・履歴・設定は `~/Library/Application Support/Gloss/` に JSON で保存する。

## ビルドとインストール

```sh
./scripts/install.sh     # ビルドして ~/Applications/Gloss.app に入れる(前のものは置き換える)
./scripts/build-app.sh   # build/Gloss.app を作るだけ
swift test               # GlossCore のテスト
```

Xcode 26 / Swift 6.3 で確認している。
カードの文字が1文字ずつ入れ替わる動きは macOS 15 以上で、macOS 14 ではふわっと切り替わる。

## 構成

画面ごとに、見た目(Page)と状態(Store)を同じフォルダに置いている。
Store は `private(set)` の state を1つ持ち、書き換えは Store のメソッドからだけにしている。

```
Sources/
├── Gloss/                    アプリ(SwiftUI)
│   ├── GlossApp.swift        Store を作って画面に渡す
│   ├── Router/               サイドバーの行き先(AppRoute)
│   ├── Pages/
│   │   ├── Translate/        翻訳画面
│   │   ├── Ask/              右の質問パネル
│   │   ├── Words/            単語帳(フラッシュカード)
│   │   ├── History/          履歴
│   │   ├── Settings/         設定
│   │   └── Root/             分割ビューとサイドバー
│   └── Widgets/              画面をまたいで使う部品
└── GlossCore/                UI に依存しない部分(テストあり)
    ├── Models/               単語・履歴・設定などのデータ
    └── Repositories/         AI との通信・プロンプト・保存・Keychain
```

Store どうしの依存は一方向だけ(矢印の先が、元の Store を使う)。

```
SettingsStore ──> WordsStore ──> AskStore
      │                             ▲
      ├─────────────────────────────┘
      └──────────────> TranslateStore <── HistoryStore
```
